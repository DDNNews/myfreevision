# MyFreeVision

Persönliche WebApp für Vision, Ziele, Gewohnheiten und Fortschritt. Läuft auf iPhone und Mac.

**App öffnen:** https://ddnnews.github.io/myfreevision/

Installation: Adresse in Chrome öffnen, Teilen, „Zum Home-Bildschirm“ (iPhone) bzw. Menü, „Seite als App installieren“ (Mac).

Alle Daten bleiben lokal auf dem jeweiligen Gerät.
